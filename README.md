# SaySomething

SaySomething is a civic reporting platform that allows citizens
to report public issues and anomalies to the appropriate authorities.

## User Roles

- Citizen
- Authority
- Administrator

## Report Categories

- Roads
- Electricity
- Water
- Environment
- Public Safety

## Report Lifecycle

Submitted → Under Review → Assigned → In Progress → Resolved

## Technology Stack

- Frontend: React
- Backend: Python FastAPI
- Database: PostgreSQL + PostGIS
- Version Control: Git/GitHub
